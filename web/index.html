NFS-e Validador

Descubra se o seu XML de NFS-e esta correto antes de contratar uma API que so libera homologacao depois do pagamento.

🔒 100% offline · seu XML nao sai deste navegador

Arraste seu .xml aqui, ou clique para escolher o arquivo

    O que esta ferramenta NÃO faz

    Para nao te wasting tempo depois, sendo direto:

    • Nao verifica assinatura digital. Nao valida criptografia XMLDSig/RSA nem certificado. Usamos uma biblioteca de assinatura de verdade para isso.
    • Nao valida contra o XSD do seu municipio. Cada prefeitura tem um schema proprio. Aqui checamos regras estruturais e aritmeticas comuns ao padrao ABRASF.
    • Nao substitui a homologacao do provedor. Se voce precisa saber se o seu caso especifico passa, o unico jeito e submeter ao provedor.
    • Nao e advice juridico ou tributario. Isto e uma ferramenta de desenvolvimento.

    Regras aritmeticas conferidas

    • vServicos = soma do vServ dos itens
    • vBC = soma das bases de calculo dos itens
    • vISS = soma dos ISS dos itens
    • vTotTrib = soma dos tributos dos itens
    • vLiq = base menos vDescIncond menos vDeducao
    • Sem itens declarados, os totais tem que ser zero

    Tolerancia de 0,01 (um centavo) para nao acusar erro por arredondamento.
